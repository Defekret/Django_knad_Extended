# Django_knad_Extended

Каталог телефонов на Django. Продолжение проекта [Django_knad](https://github.com/Defekret/Django_knad):
к сайту добавлен сервер с API, чтобы потом можно было написать отдельный клиент.

Shakirova Dinara 222

## Идея

Приложение для одного пользователя, без авторизации. В каталоге хранятся телефоны с характеристиками.
Их можно искать, фильтровать, сравнивать между собой и добавлять в избранное.
Сервер хранит данные и отдаёт их в JSON, клиент будет во второй части.

## Функциональные требования

1. Просмотр списка телефонов по страницам
2. Просмотр одного телефона
3. Добавление телефона
4. Изменение телефона
5. Удаление телефона
6. Фильтр по бренду, операционной системе, цене, памяти и наличию
7. Поиск по названию и сортировка
8. Сравнение двух телефонов (у кого лучше цена, экран, камера и память)
9. Избранное: добавить, убрать, посмотреть список
10. Статистика по каталогу (сколько телефонов, сколько в наличии, цены, количество по брендам)

## Нефункциональные требования

1. Список из 1000 телефонов отдаётся быстрее 0.5 секунды
2. За один запрос отдаётся не больше 100 телефонов
3. Неправильные данные не сохраняются: цена и количество не меньше 0, рейтинг от 0 до 10. Сервер отвечает 400 и пишет, в каких полях ошибка
4. Обмен данными в формате JSON, используются обычные коды HTTP (200, 201, 204, 400, 404)
5. Данные лежат в базе SQLite и не пропадают после перезапуска, структура базы меняется через миграции
6. SECRET_KEY и DEBUG можно задать через переменные окружения
7. Сервер запускается в Docker одной командой
8. На каждое функциональное требование есть тест
9. Есть адрес для проверки, что сервер работает, запросы пишутся в консоль
10. Все методы API описаны в README

## Запуск

```
cd project
pip install -r requirements.txt
python manage.py migrate
python manage.py loaddata demo
python manage.py runserver
```

`loaddata demo` добавляет 5 телефонов для примера.

Или через Docker:

```
docker compose up --build
```

Сайт: http://127.0.0.1:8000/phones/

API: http://127.0.0.1:8000/api/phones

Тесты:

```
python manage.py test
```

## API

| Метод | Адрес | Что делает |
|---|---|---|
| GET | /api/phones | список телефонов |
| POST | /api/phones | добавить телефон |
| GET | /api/phones/1 | один телефон |
| PATCH | /api/phones/1 | изменить телефон |
| DELETE | /api/phones/1 | удалить телефон |
| GET | /api/phones/compare?first=1&second=2 | сравнить два телефона |
| POST | /api/phones/1/favorite | добавить в избранное |
| DELETE | /api/phones/1/favorite | убрать из избранного |
| GET | /api/favorites | избранное |
| GET | /api/stats | статистика |
| GET | /api/health | проверка сервера |

Параметры списка:

- `page`, `page_size` - страница и её размер (по умолчанию 20, максимум 100)
- `brand`, `os` - бренд и операционная система
- `price_min`, `price_max` - цена
- `storage_min` - память
- `in_stock=true` - только в наличии
- `search` - поиск по названию и бренду
- `ordering` - сортировка: `price`, `rating`, `screen_size`, `camera_resolution`, `storage`, `brand`, `model_name`. С минусом в обратном порядке, например `-price`

Пример:

```
curl "http://127.0.0.1:8000/api/phones?brand=samsung&ordering=-price"
```

Добавление телефона:

```
curl -X POST http://127.0.0.1:8000/api/phones -H "Content-Type: application/json" -d '{"model_name": "Galaxy S23", "brand": "Samsung", "price": 69990, "color": "green", "operation_system": "Android", "screen_size": 6.1, "preview_text": "Описание", "rating": 9, "camera_resolution": 50, "stock_quantity": 7, "storage": 256}'
```

В сравнении возвращаются оба телефона и лучшие значения: `best_price`, `best_screen_size`, `best_camera`, `best_storage`.
Если значения одинаковые, там `null`.
